# Lindsay Vanhecke

Persoonlijke website van Lindsay Vanhecke, psycholoog gespecialiseerd in
psychodiagnostisch onderzoek bij kinderen, jongeren en volwassenen.

Gebouwd met React + Vite, gedeployed via Cloudflare.

## Ontwikkelen

```bash
npm install
npm run dev
```

## Bouwen

```bash
npm run build
```
